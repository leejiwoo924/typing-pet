타이핑펫 Mac 배포 — Windows만 있을 때
================================

Mac 컴퓨터 없이 .dmg 를 만드는 방법입니다.

1. 이 프로젝트를 GitHub에 올립니다.
2. GitHub → Actions → "Build Mac" → Run workflow
3. 빌드가 끝나면 Artifacts 에서 파일을 받습니다.
4. 받은 폴더를 구글 드라이브 등에 공유합니다.

받는 Mac 사용자:
- dmg 설치 후 "손쉬운 사용" 권한을 켜야 타이핑에 반응합니다.
- 경고가 뜨면 우클릭 → 열기

자세한 내용: mac/README.md
